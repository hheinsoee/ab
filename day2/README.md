# Day 2 — Color Changer

ဒီနေ့ — HTML, CSS, JavaScript ဆိုတဲ့ **web ရဲ့ ပင်မ ၃ ပိုင်း** ကို ပထမဆုံး မြင်မယ်။

Button တစ်ချက်နှိပ်တိုင်း heading ရဲ့ အရောင် ပြောင်းသွားမယ့် simple page တစ်ခု။

---

## ဖိုင် ၃ ခု — တစ်ခုချင်း ဘာလုပ်လဲ

### `index.html` — ဖွဲ့စည်းပုံ (Structure)

HTML က **ဘာတွေ ပါတယ်** ဆိုတာ ပြော။

- `<h1>` — ကြီးမားတဲ့ စာသား (heading)
- `<button>` — နှိပ်လို့ရတဲ့ button
- `<link>` — CSS ဖိုင်ကို ချိတ်
- `<script>` — JS ဖိုင်ကို ချိတ်

**Analogy**: HTML က **အိမ်ရဲ့ အုတ်မြစ် + နံရံ** လိုမျိုး — ပုံစံ ဘယ်မှာ, ဘာရှိတယ် ဆိုတာ သတ်မှတ်။

---

### `styles.css` — အသွင်အပြင် (Looks)

CSS က **ဘယ်လိုမြင်ရမလဲ** ဆိုတာ ပြော။

- အရောင် (`color`, `background`)
- အရွယ်အစား (`font-size`, `padding`)
- နေရာချမှု (`display`, `margin`)
- Hover ဖြစ်ရင် ဘာဖြစ်မလဲ (`:hover`)

**CSS က ဘာအတွက်လဲ?**
→ Page ကို **အလှအပ** ပြုလုပ်။ Color, font, spacing, layout — အကုန် CSS။

**Analogy**: CSS က **အိမ်ကို ဆေးသုတ်, ပရိဘောဂ ချ, မီးထည့်** လိုမျိုး — အသွင်အပြင်ပဲ သက်ဆိုင်။

---

### `script.js` — လှုပ်ရှားမှု (Behavior)

JS (JavaScript) က **ဘာလုပ်မလဲ** ဆိုတာ ပြော။

- Button click — "နှိပ်တယ်" ဆိုတာ သိ
- Element ကို ရှာ — `getElementById`
- အရောင် ပြောင်း — `style.color = ...`

**JS က ဘာအတွက်လဲ?**
→ Page ကို **interactive** ဖြစ်အောင်။ User က နှိပ်, scroll, type လုပ်တဲ့အခါ ဘာဖြစ်မလဲ ဆိုတာ ထိန်းချုပ်။

**Analogy**: JS က **အိမ်ရဲ့ switch, remote control, automation** လိုမျိုး — ဘာမှ မလှုပ်ဘဲ ထိုင်နေတဲ့ အိမ် (HTML+CSS) ကို အသက်ဝင်စေ။

---

## အတွဲ ၃ ခု ဘယ်လို အတူတူ အလုပ်လုပ်လဲ

```
HTML  →  "button တစ်ခု ရှိတယ်"
CSS   →  "ဒီ button က အပြာရောင်, round shape"
JS    →  "button နှိပ်ရင် heading color ပြောင်း"
```

၃ ခုလုံး **အတူတူ ပေါင်းစပ်မှ** website တစ်ခု ဖြစ်မယ်။ တစ်ခုမပါရင် မပြည့်စုံ —

- HTML မပါ → ဘာမှ ပေါ်မလာ
- CSS မပါ → ပေါ်ပေမဲ့ မလှ
- JS မပါ → လှပေမဲ့ လှုပ်မရ (static)

---

## စမ်းကြည့်မယ်

1. `index.html` ကို browser မှာ ဖွင့်
2. "Change color" button ကို နှိပ်
3. Heading ရောင် ပြောင်းသွားတာ မြင်မယ်

**Code ဖိုင်တွေ ဖတ်ကြည့်** — comment တွေ ထည့်ထား, တစ်ကြောင်းချင်း ဘာလုပ်လဲ ရှင်းပြထား။

---

## ဒီနေ့ လေ့လာမယ့် အရာ

| စကားလုံး | ဘာလဲ |
|---|---|
| **HTML** | Page ရဲ့ ဖွဲ့စည်းပုံ (ဘာပါတယ်) |
| **CSS** | Page ရဲ့ အသွင်အပြင် (ဘယ်လိုမြင်ရလဲ) |
| **JS** | Page ရဲ့ လှုပ်ရှားမှု (ဘာလုပ်မလဲ) |
| **element** | HTML ထဲက တစ်ခုချင်း (ဥပမာ: `<h1>`, `<button>`) |
| **id** | Element ကို ရှာဖို့ သုံးတဲ့ unique နာမည် |
| **event** | ဖြစ်ပျက်မှု (ဥပမာ: button click) |
| **external file** | HTML ထဲမှာ မပါဘဲ, သီးသန့် ဖိုင်ထဲ ထား (`styles.css`, `script.js`) |

---

## အခု — ကိုယ့်ဖာသာ စမ်း

၁။ `styles.css` ထဲက `background: #f5f5f5;` ကို `background: #000;` ပြောင်း — ဘာဖြစ်မလဲ?

၂။ `script.js` ထဲက `colors` array ထဲမှာ ကိုယ့်ကြိုက်တဲ့ အရောင် ထည့် (ဥပမာ: `"#ff69b4"` ပန်းရောင်)

၃။ `index.html` ထဲ `<button>` ကို copy, နောက်တစ်ခု ထည့် — JS က ဘာလို့ ဒုတိယ button ကို မသိတာလဲ?

ဒီ ၃ ချက်ကို စမ်းကြည့်ပြီးရင် — HTML, CSS, JS ဘယ်လို ချိတ်ဆက်လဲ ဆိုတာ သိသွားမယ်။
